LOGIN 1. Login sa GitHub via Termux (gh CLI)

pkg install -y git gh # LOGIN - 2 options: # OPTION A: Browser login (mas madali sa phone) gh auth login # -> What account? GitHub.com # -> What is your preferred protocol? HTTPS # -> Authenticate Git? Yes # -> How to authenticate? Login with a web browser # -> Copy one-time code, open browser, paste code, authorize # OPTION B: Token login (pag ayaw ng browser) # 1. Pumunta sa github.com > Settings > Developer settings > Personal access tokens > Tokens (classic) > Generate new token # 2. Check: repo, workflow, write:packages, delete:packages # 3. Copy token gh auth login --with-token # paste token + Enter # check kung logged in gh auth status # dapat: Logged in to github.com as jonelzky (yung username mo) # kung failed, logout tapos login ulit gh auth logout gh auth login

CONFIG 2. Git Config (one-time setup)

git config --global user.name "Jonel Garvin Malabayabas" git config --global user.email "jonel@example.com" # check git config --global --list # dapat may user.name at user.email # kung gusto mo i-check lahat cat ~/.gitconfig # set default branch to main (hindi master) git config --global init.defaultBranch main
✅ GOOD PRACTICE:
Lagi mo i-set yung user.name at user.email bago mag-commit, kasi kung hindi, mag-eerror yung git commit!

CREATE 3. Gawa ng Repo - 3 Methods

METHOD A: Auto create + push (pinaka-madali - ginamit natin sa BSRTSum!)

cd ~/BSRTSum_Final # or kung saan yung project mo # dapat may files ka na dito: index.html, etc git init git add . git commit -m "Initial BSRTSum" # ISANG COMMAND LANG - gawa repo + push! gh repo create BSRTSum --public --source=. --remote=origin --push # -> Creates repo jonelzky/BSRTSum sa GitHub + push lahat! # check gh repo view # dapat may URL na: https://github.com/jonelzky/BSRTSum

METHOD B: Manual via website tapos push

cd ~/MyApp git init git add . git commit -m "Initial" # gawa repo sa github.com website manually # tapos copy yung URL git remote add origin https://github.com/jonelzky/MyApp.git git branch -M main git push -u origin main

METHOD C: Clone existing repo tapos edit

# kung may existing repo ka na cd ~ git clone https://github.com/jonelzky/BSRTSum.git cd BSRTSum # edit files nano index.html git add index.html git commit -m "Update index" git push

PUSH 4. Push Updates - Daily Workflow

# araw-araw na gagawin pag may binago ka cd ~/BSRTSum_Final # check status git status # makikita kung ano nabago # add lahat ng nabago git add . # or specific file lang # git add index.html BSRTSum.apk # commit git commit -m "Update: add new feature" # push git push # kung first time mo mag-push at nag-error na "no upstream" git push -u origin main # check sa github.com/jonelzky/BSRTSum - dapat updated na!

⚠️ PAG MAY CONFLICT (may nabago sa GitHub na wala sa phone mo)

git pull --rebase # kung may conflict, edit mo yung file na may <<<< >>>> nano index.html # ayusin, tapos git add index.html git rebase --continue git push

PAGES 5. Deploy to GitHub Pages - Para Maging Website!

Step 1: Dapat may index.html sa ROOT, hindi sa subfolder!
cd ~/BSRTSum_Final ls -lh # dapat may index.html dito mismo, hindi sa app/ or docs/ # kung wala, copy mo: cp app/src/main/assets/index.html index.html # or kung iba name ng HTML mo: cp KimSumSum.html index.html git add index.html git commit -m "Add index.html for Pages" git push
Step 2: Enable Pages sa GitHub website
# Hindi to sa Termux, sa browser gawin: # 1. Pumunta sa github.com/jonelzky/BSRTSum # 2. Click Settings (tab sa taas) # 3. Sa left sidebar, click Pages # 4. Under "Build and deployment", Source: Deploy from a branch # 5. Branch: main / root (hindi docs!) # 6. Click Save # 7. Wait 1-2 mins, may lalabas na: # "Your site is live at https://jonelzky.github.io/BSRTSum/" # Check kung live na: curl -I https://jonelzky.github.io/BSRTSum/ # dapat HTTP/2 200, hindi 404! # kung 404 pa, wait lang 2-3 mins, nagbi-build pa si GitHub!
Step 3: Main Hub - jonelzky.github.io (yung may 4-6 apps list)
cd ~/github-bsrt # or kung saan mo na-clone yung jonelzky.github.io repo git clone https://github.com/jonelzky/jonelzky.github.io.git cd jonelzky.github.io # edit index.html, dagdag mo new app card nano index.html # add mo: # BSRTSum git add index.html git commit -m "Add BSRTSum to hub - now 5 apps" git push # after 2 mins, live na sa https://jonelzky.github.io/

ERRORS 7. TROUBLESHOOT - Lahat ng Error na Na-fix Natin!

❌ ERROR 1: Space in /tmp/ github-bsrt - fatal: cannot create directory
fatal: cannot create directory at '/tmp/ github-bsrt': Invalid argument # may space sa path!
✅ FIX: Wag gumamit ng folder na may space! Sa Termux, yung /tmp minsan nagiging "/tmp/ github-bsrt" (may space)!

Dapat:
cd ~/github-bsrt <- nasa HOME, walang space!
Hindi:
cd "/tmp/ github-bsrt" <- may space, error!

Fix:
mkdir -p ~/github-bsrt
cd ~/github-bsrt
git clone ...
❌ ERROR 2: git init sa HOME - /data/data/com.termux/files/home/.git - NAGKAGULO!
Initialized empty Git repository in /data/data/com.termux/files/home/.git/ # Nasa HOME ka nag git init, hindi sa project folder!
✅ FIX: Dapat sa project folder ka mag git init, hindi sa ~!

MALI:
cd ~
git init <- LAHAT NG FILES SA HOME MAGIGING GIT REPO! DELIKADO!

TAMA:
cd ~/BSRTSum_Final
git init <- dito lang sa project folder!

Kung nagkamali ka, delete mo:
rm -rf ~/.git
cd ~/BSRTSum_Final
git init
❌ ERROR 3: Read-only file system /tmp
error: cannot open /tmp/... Read-only file system
✅ FIX: Sa Termux, yung /tmp minsan read-only! Gamitin mo ~/tmp or $PREFIX/tmp!

mkdir -p ~/tmp
export TMPDIR=~/tmp
cd ~/BSRTSum_Final
git push

Or lagay mo sa ~/.bashrc:
echo 'export TMPDIR=$HOME/tmp' >> ~/.bashrc
❌ ERROR 4: GitHub Pages 404 - Site not found
404 - There isn't a GitHub Pages site here.
✅ FIX:
1. Check kung may index.html sa ROOT ng main branch (hindi sa docs/ or app/)
git ls-files | grep index.html
# dapat may index.html sa list

2. Check Pages settings: github.com/USER/REPO > Settings > Pages > Source: main / root (hindi docs!)

3. Wait 2-3 mins, nagbi-build pa!

4. Check curl:
curl -I https://jonelzky.github.io/BSRTSum/
# dapat 200, hindi 404

5. Kung wala pa rin, push ka ulit ng empty commit:
git commit --allow-empty -m "Trigger Pages build"
git push
❌ ERROR 5: remote origin already exists
fatal: remote origin already exists.
✅ FIX:
# remove muna old remote
git remote remove origin
# add ulit
git remote add origin https://github.com/jonelzky/BSRTSum.git
git push -u origin main

Or check remotes:
git remote -v
❌ ERROR 6: Authentication failed / gh auth login failed
failed to authenticate via web browser HTTP 401: Bad credentials
✅ FIX:
gh auth logout
gh auth login
# piliin: GitHub.com > HTTPS > Yes > Login with a web browser
# copy code, open browser, paste, authorize

Or token method:
gh auth login --with-token
# paste personal access token (classic) na may repo scope

Check:
gh auth status
❌ ERROR 7: failed to push - Updates were rejected / need to pull
! [rejected] main -> main (fetch first) hint: Updates were rejected because the remote contains work that you do not have locally.
✅ FIX:
git pull --rebase
# ayusin conflicts kung meron
git push

Or force push kung sure ka (delikado, mawawala remote changes!):
git push -f origin main <- GAMITIN LANG PAG SURE KA!
❌ ERROR 8: gh repo create failed - Name already exists
GraphQL: Name already taken (createRepository)
✅ FIX: May existing repo na na same name! 2 options:

1. Gamitin existing repo:
git remote add origin https://github.com/jonelzky/BSRTSum.git
git push -u origin main

2. Delete old repo sa github.com website > Settings > Danger Zone > Delete repository
Tapos gawa ulit:
gh repo create BSRTSum --public --source=. --remote=origin --push
